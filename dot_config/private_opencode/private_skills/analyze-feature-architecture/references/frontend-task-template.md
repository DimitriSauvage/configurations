# Feature Task Template

Use this format for each decomposed task.

```markdown
### Task N - [Concise Title]

**Scope:** [component | page | composable | store | translation | mock | infrastructure | test]

**Business Rules (RG):**

- RG-01: ...

**Acceptance Criteria (AC):**

- AC-01: ...

**What to implement:**

- Files: ...
- Contracts: ...
- Data flow: ...

**Dependencies:** [Task N | none]
```

Checklist:

- Is this task independently executable?
- Are dependencies explicit?
- Are acceptance criteria testable?
- Is i18n included when UI labels are added?
